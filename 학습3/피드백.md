잘된 점: 
마우스가 카드위로 이동할 떄 카드가 살짝 움직이는 반응이 좋았음
카드는 큰데 텍스트만 있는 것은 향후 이미지 포함하는 확장성이 보임

고치면 좋을 점
1. 본것 : 등급설정이 된 상태에서 같은 브라우저의 다른 창에서 열면 초기화 상태로 돌아가 있음
   기준 : 기획서의 [같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.]
   제안 : 같은 파일을 다시 열어도 보이도록 저장 기능 추가
2. 본것 : 빈 제목 상태에서 추가를 누르면 글자 없는 카드가 생김
   기준 : 기획서의 [제목을 입력하면 새 영화 카드가 생깁니다.]
   제안 : 빈 제목인 경우 경고 메시지와 함께 추가 안되도록 함
3. 본것 : 카드색이 회색으로 분위기가 어두움
   기준 : 기획서에는 없음
   제안 : 색을 선택할 수 있는 기능 추가
4. 본것 : 카드 크기에 비해 제목만 나옴. 여백이 많음
   기준 : 기획서에는 없음
   제안 : 영화 포스터로 보이면 좋을 것 같고, 이미지가 없는 경우, 텍스트 정렬이 필요함
