# 🎬 영화 티어리스트 웹페이지 기획서

## 1. 프로젝트 개요
영화를 나만의 기준(S~D 등급)으로 분류하고, 드래그로 배치하여
개인 취향을 기록하고 공유할 수 있는 웹페이지.

- **프로젝트명:** 영화 티어리스트
- **형태:** 단일 HTML 파일 (외부 파일 없음)
- **작성 도구:** 순수 HTML / CSS / JavaScript

---

## 2. 기획 결정 사항

| 항목 | 결정 내용 |
|------|-----------|
| 사용자층 | 공개 웹서비스 (누구나 사용 가능) |
| 목적 | 개인 기록 + 이미지/링크 공유 |
| 데이터 입력 | 직접 입력 + 미리 준비된 목록 병행 |
| 기술 스택 | HTML / CSS / JavaScript (순수, 단일 파일) |
| 저장 방식 | localStorage (브라우저 내 저장) |

---

## 3. 주요 기능

1. **티어 표시** — S / A / B / C / D 5단계 색상 티어
2. **드래그 배치** — 영화 카드를 끌어 원하는 티어에 배치
3. **티어 커스텀** — (향후) 티어 이름/색상 변경
4. **검색 추가** — 제목 입력으로 영화 추가
5. **포스터 이미지** — 포스터 URL 입력 시 이미지 표시, 없으면 제목 글자
6. **이미지 안전장치** — 깨진 포스터는 자동으로 제목으로 대체
7. **저장 / 불러오기** — localStorage에 보관
8. **초기화** — 순위만 비우고 영화는 대기 목록에 유지

---

## 4. 화면 구성

- **상단:** 제목 + 입력 영역(제목, 포스터 URL, 추가/저장/불러오기/초기화 버튼)
- **중앙:** 티어 행 (S~D), 각 행에 영화 카드 드롭 가능
- **하단:** 대기 목록 (아직 배치하지 않은 영화 보관)

## 6. 개발 단계

### ✅ 1단계 (완료)
- 티어 표시
- 드래그 배치
- 영화 추가 (직접 입력 + 기본 목록)
- 포스터 이미지 표시
- 저장 / 불러오기
- 초기화

### 🔜 향후 단계 (아이디어)
- 티어 이름 / 색상 커스텀
- 영화 삭제 버튼
- 포스터 크기 조절
- 이미지로 내보내기(캡처)
- 결과 링크 공유
