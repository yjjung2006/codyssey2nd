# 🎾 테니스 중계 알림 대시보드 기획서

## 1. 프로젝트 개요
- **대상 사용자**: 테니스 대회(그랜드슬램, ATP/WTA 투어 등) 중계 일정을 놓치고 싶지 않은 테니스 팬
- **사용 목적**: 흩어져 있는 TV/OTT(SPOTV, tvN SPORTS, 티빙 등) 중계 일정을 한눈에 확인하고, 본인이 원하는 조건(관심 선수, 대회 등)에 맞춰 이메일/슬랙 알림을 설정하기 위함.
- **서비스 형태**: HTML 단일 파일 (`index.html`) 기반의 로컬 대시보드 (설정값은 브라우저 `localStorage`에 저장)

---

## 2. 화면 구성과 동작 (HTML 단일 파일)

### 2.1. 전체 레이아웃
- **좌측 사이드바 (알림 설정 영역)**
  - 알림 수단 선택 (이메일 / 슬랙)
  - 필터링 조건 설정 (관심 선수 이름, 8강 이상 등)
  - [설정 저장] 버튼
- **우측 메인 영역 (데이터 확인 영역)**
  - 상단: 이번 주 주요 테니스 대회 요약
  - 중단: 수집된 TV/OTT 중계 일정 표 (날짜, 대회명, 경기, 중계 채널, 링크)
  - 하단: 알림 발송 테스트 버튼 (클릭 시 파이썬 스크립트와 연동할 수 있는 안내 팝업)

### 2.2. 주요 동작 흐름
1. 사용자가 `index.html`을 브라우저에서 엽니다.
2. 좌측 사이드바에서 본인의 이메일 주소나 관심 선수를 입력하고 [저장]을 누릅니다.
3. 입력된 정보는 브라우저의 `localStorage`에 저장되어 창을 닫아도 유지됩니다.
4. 우측 화면에는 파이썬이 미리 수집해 둔 데이터(예: `data.json`)를 불러와 표 형태로 보여줍니다.

## 3. 기능 명세 (필수 vs 추가)

### 🟢 필수 기능 (MVP - 현재 목표)
1. **UI 렌더링**: 사이드바와 메인 콘텐츠 영역을 나누어 깔끔하게 표시 (CSS 활용).
2. **설정 저장/불러오기**: 사용자가 입력한 알림 조건(이메일 주소, 관심 선수 등)을 `localStorage`에 저장하고, 페이지 새로고침 시 불러옴.
3. **데이터 표시**: 로컬에 저장된 가상의 중계 일정 데이터(JSON 형식)를 읽어와 HTML 표(Table)로 화면에 뿌려줌.
4. **플랫폼 뱃지 표시**: 중계 채널(SPOTV, 티빙 등)에 따라 색상이 다른 태그나 파비콘을 표시하여 가독성 향상.

### 🔵 추가 기능 (향후 고도화 - 현재 범위 제외)
1. **로그인 및 회원가입**: 사용자별 계정 생성 및 클라우드 동기화 기능.
2. **API 키 및 서버 연동**: 
   - 슬랙 웹훅 URL이나 이메일 앱 비밀번호를 화면에서 직접 입력받아 실제 서버(DB)로 전송하는 기능.
   - 백엔드 서버(Node.js, Django 등)를 구축하여 24시간 자동 크롤링 및 발송 처리.
3. **AI 및 챗봇 기능**:
   - 챗봇에게 "오늘 알카라스 경기 언제야?"라고 물어보면 대답해 주는 기능.
   - AI를 활용한 지난 경기 하이라이트 자동 요약 기능.
4. **바로 보기**: 화면에서 클릭하면 해당 중계를 바로 볼 수 있는 기능. 재방송 또는 Youtube 동영상 파일 재생
---

## 4. 필요한 자료
- **디자인 리소스**: 테니스공 아이콘(파비콘), 각 방송사/OTT 로고 이미지 또는 브랜드 컬러 코드.
- **샘플 데이터**: 화면에 띄워볼 가상의 테니스 중계 일정 데이터 (`matches.json` 파일).
- **파이썬 스크립트**: (화면 밖에서 동작) 실제 데이터를 수집하고 메일/슬랙을 발송할 완성된 파이썬 코드.

---

## 5. 한계 및 비목표 (Out of Scope)
- **비목표 1**: 실시간 경기 스트리밍 영상 제공 (저작권 문제로 링크만 제공).
- **비목표 2**: 결제 시스템 도입 (완전 무료 개인용 툴로 기획).
- **한계점**: HTML 단일 파일이므로, 브라우저를 켜두지 않거나 파이썬 스크립트를 스케줄러(cron 등)에 등록하지 않으면 '완전 자동화'는 어려움. (현재는 로컬 환경에서의 개인 맞춤형 대시보드에 의의를 둠).

---

## 6. 완료 기준 및 검증 방법

### ✅ 완료 기준
- `index.html` 파일 하나만 더블클릭해서 열었을 때 화면이 깨지지 않고 정상적으로 렌더링될 것.
- 사이드바에 관심 선수(예: '조코비치')를 입력하고 저장한 뒤, 브라우저를 껐다 켜도 해당 설정이 유지될 것.
- 메인 화면에 중계 일정 표가 가독성 좋게 표시될 것.

### 🔍 검증 방법
1. **크로스 브라우징 테스트**: Chrome, Edge, Safari 등 다양한 브라우저에서 `index.html`을 실행해 UI 확인.
2. **로컬 스토리지 테스트**: 개발자 도구(F12) -> Application -> Local Storage 탭에서 입력한 설정값이 정확히 JSON 형태로 저장되는지 확인.
3. **데이터 연동 테스트**: 파이썬이 만들어낸 `data.json` 파일의 내용을 수정했을 때, HTML 화면을 새로고침하면 변경된 데이터가 즉시 반영되는지 확인.
