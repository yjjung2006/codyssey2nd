# 상품 리뷰 기반 마케팅 포인트 추출 시스템 설계

## 1. 과업 정의

| 항목 | 내용 |
|---|---|
| 과업 | 상품 리뷰에서 향후 차별화된 마케팅 포인트 추출 |
| 타겟 사용자 | 제품 마케팅 담당자 |
| 입력 | 상품 리뷰 전문 |
| 출력 | 마케팅 포인트 (우선순위별) |

## 2. 페르소나

| 항목 | 내용 |
|---|---|
| 이름 | 제품 마케팅 담당자 |
| 역할 | 상품 리뷰에서 중요 내용을 뽑아 정리하는 담당자 |
| 전문 분야 | 상품 리뷰 정리 및 보고 |
| 말투 | 간결하고 사실만 적는 문장 |
| 금지 사항 | 리뷰 내용을 각색하거나, 애매한 표현을 추정하여 정리하지 않는다 |
| 우선순위 | 많이 언급되는 내용보다 차별화된 리뷰 내용 우선 |

## 3. 시스템 프롬프트 (v2)

> **카테고리:** 페르소나

```text
너는 마케팅 담당자야. 고객 리뷰에서 차별화된 마케팅 포인트를 근거와 해당 원문 포함하여 뽑아줘. 리뷰의 내용을 각색하지 마.
```

## 4. 입력 템플릿

> **카테고리:** 텍스트 생성

```text
고객리뷰 : {고객리뷰 전문}
기준: {상품스펙에 대한 평이 포함된 리뷰를 대상으로 선정, 단순한 표현의 상품리뷰는 제외}
출력: 향후 마케팅 포인트 선정 및 이를 근거로 최고리뷰 3개 선정
```

## 5. 사용자 프롬프트

> **카테고리:** 텍스트 생성 (전 버전 공통)

### 5.1 Zero-shot

**v1**

```text
각 리뷰 내용을 3줄 정도로 요약해 줘.
최고 리뷰 3개 선정하고 이유를 적어줘
```

### 5.2 Few-shot 1

**v2**

```text
향후 마케팅에 활용할 수 있는 리뷰를 우선으로 해줘, 필요하면 객관식으로 문의해줘.
최고 리뷰 3개 선정하고 3줄정도로 요약하고, 선정 이유를 적어줘
```

**v2.1**

```text
- 부정 내용이 일부 있어도 구체성이 높은 리뷰를 포함하여 다시 선정
- 결과는 템플릿으로 만들어줘
```

### 5.3 Few-shot 2

**v3**

```text
향후 마케팅에 활용할 수 있는 포인트가 있는 리뷰를 우선으로 해줘, 필요하면 객관식으로 문의해줘.
1-5점 내에서 점수화해줘
최고 리뷰 3개 선정하고 이유를 적어줘
```

**v3.1**

```text
- 평가 기준 가중도에 대해 다시 검토하여 다시 실행
- 리뷰내 핵심 내용을 마케팅 포인트를 뽑고
- 3개 선정
- 결과는 템플릿으로 만들어줘
```

### 5.4 Few-shot 3

**v4**

```text
향후 마케팅에 활용할 수 있는 포인트가 있는 리뷰를 우선으로 해줘, 필요하면 객관식으로 문의해줘.
가성비/디자인/세척편리성/피부자극/절삭력 기준으로 1-5점으로 점수화해서 정리
최고 리뷰 3개 선정하고 이유를 적어줘
```

**v4.1**

```text
- 각 항목을 얼마나 잘 리뷰했는지를 우선으로 평가해줘
- 마케팅 포인트로 활용할 수 있는 내용으로 순위를 뽑아줘. 5가지에 한정하지 말고
- 차별성의 가중치를 높이고
- 경쟁사 광고 문구를 검색해 점수를 다시 매겨
- 결과는 템플릿으로 만들어줘
```

### 5.5 Few-shot 4

**v5**

```text
향후 마케팅 포인트로 활용할 수 있는 내용으로 순위를 뽑아줘, 필요하면 객관식으로 문의해줘.
차별화된 내용의 가중치를 높이고 기준/근거 제시, 필요하면 경쟁사 광고 문구를 검색해서 비교하여 순위 정리
- 이 결과를 바탕으로 최고 리뷰 3개를 뽑아줘.
- 결과는 모두 템플릿으로 만들어줘
```

## 6. 프롬프트 버전 변천 요약

| 방식 | 버전 | 주요 변경점 |
|---|---|---|
| Zero-shot | v1 | 리뷰 3줄 요약, 최고 리뷰 3개 선정 및 이유 |
| Few-shot 1 | v2 | 마케팅 활용 가능 리뷰 우선, 객관식 문의 허용, 3줄 요약 |
| | v2.1 | 부정 내용이 일부 있어도 구체성 높은 리뷰 포함, 템플릿 출력 |
| Few-shot 2 | v3 | 1-5점 점수화 추가 |
| | v3.1 | 평가 기준 가중도 재검토, 핵심 내용에서 마케팅 포인트 추출, 템플릿 출력 |
| Few-shot 3 | v4 | 평가 기준 명시: 가성비 / 디자인 / 세척편리성 / 피부자극 / 절삭력 |
| | v4.1 | 항목별 리뷰 충실도 우선, 5가지 한정 해제, 차별성 가중치 상향, 경쟁사 광고 문구 검색 후 재채점 |
| Few-shot 4 | v5 | 점수화 대신 마케팅 포인트 순위화, 기준/근거 제시, 필요 시 경쟁사 광고 비교, 순위 기반 최고 리뷰 3개 선정, 전체 템플릿 출력 |

## 7. 환각 검증

| 항목 | 내용 |
|---|---|
| 전략 | 페르소나에서 정의한 금지 사항(추론 금지, 원문 충실)을 빼고 실행 |
| 결과 | **PASS** |
| 이유 | 환각이 나오지 않았음. 원래 결과와 유사 |
| AI 답변 | 금지 사항은 "없음"으로 두었지만, 리뷰에 없는 내용은 쓰지 않았습니다.|
