
점수의 의미를 바꿔 다시 평가했습니다. 이번 점수는 만족도가 아니라 **그 항목을 얼마나 구체적으로 리뷰했는지(서술 충실도)**이고, 논조는 따로 표시했습니다. 언급이 없으면 "-"입니다.

## 턴 3: 남들이 보지 못한 내용(차별성) 우선 여부

### 사용자 프롬프트

```text
남들이 보지 못한 내용의 리뷰가 더 나은 것 아닌가?
```

### AI 응답

"절반은 맞습니다." 다른 리뷰에 없는 내용은 마케팅에서 차별화 소재가 되지만, 이것만으로 순위를 정하면 문제가 생긴다고 답했습니다.

**차별성이 중요한 이유**
- 여러 리뷰가 반복하는 말(밀착, 피부 자극 감소 등)은 소비자가 이미 기대하는 내용이라 눈에 띄기 어렵습니다.
- 한 리뷰에만 있는 소재는 캠페인에서 다른 메시지와 구분되는 훅이 됩니다.

**차별성만으로 평가하면 위험한 이유**
- 희소하다고 구매 결정에 중요한 것은 아닙니다. 예: 리뷰 2의 로켓배송 새벽 도착 이야기는 제품 정보가 아닙니다.
- 한 사람의 주장은 근거가 약하지만, 여러 리뷰가 같은 말을 하면 핵심 메시지의 신뢰도가 올라갑니다. 방수·물 세척은 리뷰 2, 3, 5, 6이, 배터리 잔량 표시는 2, 3, 5, 7이 공통으로 언급했습니다.
- 희소한 내용이 부정일 수도 있습니다. 예: 리뷰 6의 완충 전 방전 오해.

→ 공통 내용은 **핵심 메시지의 근거**로, 희소 내용은 **차별화 훅**으로 나눠 쓰는 것이 좋습니다.

**리뷰별로 다른 리뷰에 없는 내용**

| 리뷰 | 다른 리뷰에 없는 소재 | 수 |
|---|---|---|
| 6 | 5년 추가 품질보증 / 날 교체 주기 18개월·5만원대 / 날이 소프트하게 돌아가는 구조 / 물세척 후 찬바람 건조 / 파나소닉·필립스 사용 경험과의 비교 | 5 |
| 2 | 본체와 충전기만 든 실속 구성 / 설명서 없이 바로 적응하는 직관성 / 회전형 헤드가 맞지 않았던 경험과의 비교 | 3 |
| 3 | 오토센스(수염 밀도 감지) / 둥근 모서리와 윤활 코팅 / 잠금 상태 표시 | 3 |
| 5 | 5시리즈 충전기 호환(추가 비용 없음) / 배터리 표시가 점 3개에서 막대 그래프로 개선 / 실버·블랙 디자인 | 3 |
| 7 | 출장 시 충전기 없이 일주일 이상 / 정밀 트리머 기본 포함 | 2 |
| 1 | 선물하기 적당한 가격대 | 1 |
| 4, 9 | 전용 세척 스테이션 | 1 |
| 8 | AS 가능 및 기간을 구매 기준으로 제시 | 1 |

- 눈에 띄는 점: 리뷰 2는 최소 구성을 실속이라고 평가했는데, 리뷰 6은 같은 구성을 아쉽다고 썼습니다. 같은 사실에 대한 상반된 평가라 구성품 소재는 양날의 검입니다.

**차별성을 반영하면**
- 앞의 "항목별 최고 수"에 이 소재 수를 같은 비중으로 더하면 리뷰 6이 8, 리뷰 2와 3이 5, 리뷰 5가 4, 리뷰 7이 3입니다. 상위 3개(리뷰 6, 2, 3)는 바뀌지 않았습니다.
- 다만 리뷰 5와 7은 3위 안에 없는 유용한 소재를 갖고 있습니다. 보조 메시지로 활용하면 좋습니다.
  - 리뷰 5: 충전기 호환(추가 비용 없음)
  - 리뷰 7: 출장용 배터리, 정밀 트리머
- 소재 수는 AI가 원문을 읽고 센 값이라 판단이 갈릴 수 있습니다.

AI 질문: 차별성 항목과 소재 목록을 스프레드시트에 반영할까요?

## 턴 4: 5가지에 한정하지 않은 마케팅 포인트 순위

### 사용자 프롬프트

```text
마케팅 포인트로 활용할 수 있는 내용으로 순위를 뽑아줘. 5가지에 한정하지 말고
```

### AI 응답

마케팅 소재를 리뷰 전체에서 뽑아 18개로 정리하고 점수로 순위를 매겼습니다.
- 같은 내용인 리뷰 4와 9는 한 건으로 세었습니다.
- 리뷰 1은 다른 브랜드(BARUN) 후기라 제외했습니다.

**점수 기준** (각 1~5점, 종합은 가중 평균)

| 항목 | 가중치 | 설명 |
|---|---|---|
| 구체성 | 30% | 근거, 상황, 비교가 풍부한 정도 |
| 소구력 | 30% | 구매 동기를 자극하는 정도 |
| 신뢰도 | 20% | 구체적으로 긍정한 리뷰 수(1건은 1점, 5건 이상은 5점). 같은 항목을 부정한 리뷰가 있으면 1점 감점 |
| 차별성 | 20% | 일반적인 전기면도기 광고 문구와 다른 정도 |

| 순위 | 마케팅 포인트 | 점수 | 구·소·신·차 | 언급 리뷰 | 대표 원문 |
|---|---|---|---|---|---|
| 1 | 굴곡 부위 밀착 | 4.4 | 5·5·5·2 | 2, 3, 5, 6, 7 | "턱선과 굴곡을 따라 자연스럽게 움직여서 손목에 힘을 주지 않아도" (리뷰 3) |
| 2 | 피부 자극 감소 | 4.0 | 5·5·3·2 | 2, 3, 6, 7 | "피부마찰이 적으니 면도 후 스킨 바를 때 따가운 느낌이 싹 사라졌어요" (리뷰 7) |
| 3 | 한두 번에 깨끗한 절삭력 | 4.0 | 5·5·3·2 | 2, 3, 6, 7 | "여러 번 문지를 필요 없이 한두 번 지나가면 깨끗하게 잘려나갑니다" (리뷰 7) |

## 턴 5: 차별성 점수의 의미

### 사용자 프롬프트

```text
일반적인 전기면도기 광고 문구와 다른 정도?
```

### AI 응답

차별성 점수는 "광고에서 흔히 보는 소재일수록 낮게" 준 AI의 판단값이며, 실제 광고 문구를 조사해서 비교한 것은 아니라고 밝혔습니다.

**기준**

| 점수 | 설명 |
|---|---|
| 1~2점 | 거의 모든 전기면도기 광고가 내세우는 소재 (밀착, 피부 자극 감소, 절삭력, 방수) |
| 3점 | 흔하지만 구체적인 표현이 붙으면 차이가 나는 소재 (디스플레이, 강도 모드, 디자인) |
| 4~5점 | 면도기 광고에서 잘 강조하지 않는 소재 (보증, 구성, 날의 움직임, 트리머) |

**한계**
- 한두 리뷰에만 나온 소재가 높게 나왔습니다. 광고 문구와의 차이를 본다고 했지만, 실제로는 리뷰 속 희소성에 영향을 받았습니다.
- 신뢰도 점수는 언급한 리뷰 수로 계산했기 때문에, 같은 리뷰 수가 신뢰도에서는 불리하게, 차별성에서는 유리하게 작용해 서로 일부 상쇄됩니다.
- 오토센스와 5년 보증은 점수가 과대일 수 있습니다. 제조사가 직접 광고하는 기능이나 서비스일 수 있어, 제조사 광고 기준으로는 차별성이 낮을 수 있습니다. (확인하지 않음)

차별성은 리뷰 소재 순위의 보조 정보로만 보고, 광고 문구와 실제로 얼마나 다른지는 조사로 확인해야 합니다. AI는 브라운 7시리즈 상세페이지·광고 문구와 경쟁사 문구를 검색해 점수를 다시 매기겠다고 제안했습니다.
