# 내 영화 티어리스트 — 기획서 (수정본)

## 1. 개요
사용자가 영화를 S·A·B·C 등급으로 분류해 자신만의 티어리스트를 만드는 1인용 웹앱.
설치 없이 HTML 파일 하나로 동작하며, 같은 브라우저에서 다시 열면 정리한 내용이 유지된다.

- **대상**: 영화를 좋아하고 자기 취향을 정리하고 싶은 사용자
- **형태**: 단일 HTML 파일 (HTML + CSS + JavaScript)
- **저장**: 브라우저 로컬스토리지 (서버·네트워크 불필요)

---

## 2. 화면 구성
| 영역 | 설명 |
|------|------|
| 헤더 | 제목 + 사용 안내 문구 |
| 도구 바 | 영화 제목 추가 입력창, [추가] 버튼, [처음으로] 버튼 |
| 상태 메시지 | 현재 동작 안내 (선택/이동/오류 등) |
| 등급 영역 | S·A·B·C 네 줄, 각 줄에 등급 라벨 + 카드 놓는 공간 |
| 미분류 영역 | 아직 등급을 안 정한 영화 카드 모음 |

---

## 3. 등급 체계
| 등급 | 의미 | 라벨 색상 |
|------|------|-----------|
| S | 무한감동 | 붉은 벽돌색 |
| A | 재밌다 | 황토색 |
| B | 킬링타임 | 초록색 |
| C | 쓰레기 | 올리브색 |

---

## 4. 핵심 기능

### 4-1. 기본 기능 (기존)
- **초기 영화 8편 제공**: 기생충, 인터스텔라, 라라랜드 등 기본 목록 표시
- **드래그 앤 드롭**: 카드를 끌어서 원하는 등급 줄에 놓기
- **클릭 이동**: 카드 선택 → 등급 라벨 클릭으로 이동
- **영화 추가**: 입력창에 제목을 넣어 새 영화 등록 (중복·빈값 방지)
- **초기화**: [처음으로] 버튼으로 기본 목록 복원
- **로컬스토리지 저장**: 브라우저에 자동 저장, 재방문 시 복원
- **반응형 레이아웃**: 모바일 화면에서 라벨·카드 크기 자동 축소

### 4-2. 추가 기능 (이번 수정분)

#### (1) 키보드 단축키
- 카드를 선택한 상태에서 **S / A / B / C** 키를 누르면 해당 등급으로 즉시 이동
- 입력창에 글자를 쓰는 중에는 단축키가 동작하지 않음 (오작동 방지)
- Ctrl·Alt·Cmd 조합키와 함께 누르면 무시

#### (2) 등급 설명 말풍선 (신규)
- 등급 라벨(S·A·B·C)에 **마우스를 올리거나 키보드로 포커스**하면
  해당 등급의 의미를 말풍선으로 표시
  - S → "무한감동", A → "재밌다", B → "킬링타임", C → "쓰레기"
- 라벨 아래쪽에 말풍선과 화살표가 나타나며, 부드럽게 나타나고 사라짐
- **구현 포인트**: `.row`의 잘림(overflow) 설정 때문에 말풍선이 보이지 않던 문제를
  `overflow:visible`로 바꾸고, 말풍선 위치를 라벨 아래로 조정해 해결

#### (3) 접근성 강화
- 모든 카드·버튼에 `aria-label` 지정
- 선택된 카드는 `aria-pressed`로 상태 전달
- 상태 메시지 영역에 `role="status"` 적용 (스크린 리더 안내)
- 라벨 말풍선은 키보드 포커스(`:focus-visible`)에서도 표시

---

## 5. 데이터 구조
```
state = {
  nextId: 다음 영화에 붙일 번호,
  items: [ { id: "m1", title: "기생충", tier: "pool" }, ... ]
}
```
- `tier` 값: `"S" | "A" | "B" | "C" | "pool"`(미분류)
- 로컬스토리지 키: `codyssey-activity-04-v2`
- 불러올 때 형식을 검증해, 손상된 데이터면 기본값으로 안전하게 복원

---

## 6. 개인정보·안전 고려
- 네트워크 전송 없이 **본인 브라우저에만** 데이터 저장
- 파일을 다른 사람에게 보내도 입력 내역은 함께 전달되지 않음
- 저장 실패 시(브라우저 제한 등) 사용자에게 안내 메시지 표시

---

## 7. 향후 확장 아이디어
- 영화 카드에 포스터 이미지 추가
- 완성한 티어리스트를 이미지로 내보내기
- 등급 커스터마이즈(이름·색상 변경)
- 여러 티어리스트 저장·전환
