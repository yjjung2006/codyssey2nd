# 📑 [기획서] 내 영화 티어리스트 (My Movie Tier List)

**버전:** 1.1 (저장 기능 및 UI 개선 반영)  
**상태:** 구현 완료 (MVP)  
**작성일:** 2024-05-22

---

## 1. 프로젝트 개요
사용자가 자신만의 영화 등급을 매기고 관리할 수 있는 웹 기반 티어리스트 도구입니다. 직관적인 인터페이스와 데이터 보존 기능을 최우선으로 설계되었습니다.

---

## 2. 핵심 요구사항 (Requirements)

### 2.1 데이터 관리
- **초기 데이터:** 서비스 최초 접속 시 기본 8개 영화 리스트 제공
  - *기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리*
- **영화 추가:** 사용자가 입력창을 통해 실시간으로 새로운 영화 카드 생성 가능
- **영구 저장:** `localStorage`를 활용하여 브라우저 종료 후에도 데이터 유지
- **초기화:** '처음으로' 버튼 클릭 시 모든 배치를 초기화하고 초기 데이터셋으로 복구

### 2.2 등급 시스템 및 상호작용
- **등급 분류:** S, A, B, C 및 미분류(Pool) 구역
- **이동 방식 (Dual Interaction):**
  - **드래그 앤 드롭:** HTML5 Drag & Drop API를 이용한 직관적 이동
  - **클릭 이동:** 카드 선택 후 등급 라벨(S~C) 클릭 시 즉시 이동 지원 (모바일 친화적)

## 3. UI/UX 디자인 명세

### 3.1 레이아웃
- **반응형 디자인:** 
  - 데스크톱: 가로형 레이아웃
  - 모바일: 카드 2열 배치 및 가변 폭 적용
- **카드 스타일:** 
  - **중앙 정렬:** Flexbox를 사용하여 카드 내 제목을 상하좌우 정중앙(Center)에 배치
  - **시각적 피드백:** 선택된 카드에 강조 테두리 적용, 드래그 시 드롭 영역 강조

## 4. 기술 스택 (Technical Stack)

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla JS)
- **Storage:** Window.localStorage (JSON 데이터 포맷)
- **Layout:** CSS Grid & Flexbox

---

## 5. 주요 기능 구현 로직

1. **상태 관리:** `state` 객체에 영화 목록과 다음 ID 값을 저장하여 일관성 유지
2. **이벤트 위임:** 드롭 영역(`drop zone`)에 클릭 및 드롭 이벤트 리스너를 동적 부여
3. **렌더링 엔진:** 상태가 변경될 때마다 `render()` 함수를 호출하여 DOM을 최신화
4. **데이터 영속성:** `JSON.stringify`와 `JSON.parse`를 이용해 객체 데이터를 문자열로 변환하여 저장
