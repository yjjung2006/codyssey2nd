참조해서 말풍선 기능 추가해줘
코드 잘 봤어요! 사실 **말풍선 기능은 이미 전부 구현되어 있습니다.** 👏

- ✅ `TIER_DESC` 객체 정의됨
- ✅ `render()`에서 `tip` span 생성 + `label.append(tip)` 됨
- ✅ `.label .tip` CSS, `.label:hover .tip` CSS 모두 있음
- ✅ `.label { position:relative; }` 도 있음

문제는 딱 **한 군데**입니다. 바로 이 줄이에요.

```css
.row { ...; overflow:hidden; }
```

---

### 원인

말풍선은 `bottom:calc(100% + 8px)`로 **라벨 위쪽, 즉 `.row` 바깥으로** 튀어나오게 그려집니다. 그런데 부모인 `.row`에 `overflow:hidden`이 걸려 있어서 **바깥으로 나간 말풍선이 잘려 안 보이는 것**이에요. (요소는 정상적으로 만들어졌지만 화면에 안 나타나는 상태)

지난번에 제가 말씀드린 `overflow` 원인이 바로 이것이었습니다.

---

### 수정 방법 — 말풍선을 라벨 **아래쪽**으로 띄우기

`overflow:hidden`은 카드 레이아웃을 깔끔하게 유지해주니 **그대로 두고**, 말풍선만 아래로 내리는 게 가장 안전합니다. CSS 두 블록만 아래처럼 바꿔주세요.

```css
.label .tip {
  position:absolute; left:50%; top:calc(100% + 8px);   /* bottom → top 으로 변경 */
  transform:translateX(-50%);
  background:var(--ink); color:#fff; font-size:13px; font-weight:600; white-space:nowrap;
  padding:6px 10px; border-radius:8px; opacity:0; pointer-events:none; transition:opacity .15s; z-index:5;
}
.label .tip::after {
  content:""; position:absolute; bottom:100%; left:50%;   /* top:100% → bottom:100% */
  transform:translateX(-50%);
  border:6px solid transparent; border-bottom-color:var(--ink);   /* border-top-color → border-bottom-color */
}
```

그리고 `.row`도 수정합니다. (말풍선이 아래로 가도 drop 영역 안쪽이라 안전하지만, 혹시 잘릴 경우 대비)

```css
.row { display:flex; min-height:90px; background:#fff; border:1.5px solid var(--line); border-radius:14px; overflow:visible; }
```

> 💡 둘 중 **`.row`의 `overflow:visible`만** 바꿔도 원래 위쪽 말풍선이 보이긴 합니다. 다만 맨 위 S등급 말풍선이 헤더 쪽으로 튀어나가 어색할 수 있어서, **아래쪽 말풍선 방식**을 추천드려요.

---

### 바뀐 내용 요약

| 항목 | 변경 전 | 변경 후 |
|------|---------|---------|
| `.tip` 위치 | `bottom:calc(100%+8px)` | `top:calc(100%+8px)` |
| 화살표 위치 | `top:100%` | `bottom:100%` |
| 화살표 색 | `border-top-color` | `border-bottom-color` |
| `.row` | `overflow:hidden` | `overflow:visible` |

---

수정 후 **마우스를 S/A/B/C 글자에 올리거나, Tab으로 포커스**하면 말풍선이 뜰 거예요. 안 되면 F12 → Elements에서 `.row`의 `overflow` 값이 실제로 바뀌었는지 확인해 주세요.
