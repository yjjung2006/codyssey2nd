# 내 영화 티어리스트

## 누가 쓰나

- 나와 영화를 좋아하는 친구들

## 무엇을 하려고

- 본 영화를 S·A·B·C 등급으로 나누어 내 취향을 정리합니다.

## 화면과 동작

- 위에 S·A·B·C 칸, 아래에 아직 안 정한 영화 카드를 보여 줍니다.
- 카드를 누르고 등급 글자를 누르거나, 카드를 끌어 놓으면 해당 칸으로 옮겨집니다.
- **카드를 선택한 뒤 키보드 S·A·B·C 키를 누르면 해당 등급으로, Q 키를 누르면 미분류로 옮겨집니다.** *(이번에 추가)*
- 제목을 입력하고 '추가'를 누르면 아직 안 정한 영화에 카드가 생깁니다.
- 영화 목록과 등급 배치를 브라우저에 자동으로 저장합니다.
- '처음으로'를 누르면 처음 영화 목록과 배치로 돌아갑니다.

## 필요한 자료

- 기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준

- 처음 영화 8개와 새로 추가한 영화 모두 누르거나 끌어서 S·A·B·C와 미분류로 옮길 수 있습니다.
- **키보드 S·A·B·C·Q 키로도 선택한 카드를 옮길 수 있습니다.** *(이번에 추가)*
- 영화가 한 칸에만 있고, 옮긴 칸에 남습니다.
- 제목을 입력하면 새 영화 카드가 생깁니다.
- 같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다.
- 화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다.
- '처음으로'를 누르면 처음 영화 8개가 모두 미분류로 돌아갑니다.
- 외부 파일·로그인·서버 실행 없이 HTML 한 장으로 열립니다.
- 제목 입력이 비어 있거나 공백뿐이면 카드를 만들지 않고 입력 안내를 보여 줍니다.

# 변경 내역 — 키보드로 카드 옮기기 추가

## 무엇을 바꿨나

기존에는 상단 안내문에 "등급 글자를 누르세요"라고 적혀 있었지만,
실제로 **키보드를 눌러도 카드가 움직이지 않았습니다.**
이번에 **키보드로 카드를 옮기는 기능**을 추가해 안내문과 실제 동작을 맞췄습니다.

## 키 배치

- **S / A / B / C** : 선택한 카드를 해당 등급으로 옮김
- **Q** (또는 q) : 선택한 카드를 '아직 안 정한 영화(미분류)'로 옮김
- 대문자·소문자 모두 인식합니다.

## 바꾼 곳은 두 군데뿐

1. **상단 안내 문구 1줄**
   - "미분류로 보내려면 Q 키를 누르거나…" 문장을 추가했습니다.
   - 화면 디자인·색·배치는 그대로입니다.

2. **스크립트 맨 끝에 키보드 리스너 1개 추가**
   - 새 로직을 만들지 않고, 이미 있던 `move()`(옮기기)와
     `showMessage()`(안내 표시) 함수를 그대로 재사용했습니다.

### 추가한 코드 (스크립트 맨 끝 `render();` 바로 앞)

```javascript
// ▼▼▼ 여기부터 새로 추가한 부분 (키보드로 카드 옮기기) ▼▼▼
document.addEventListener('keydown', event => {
  // 1) 제목 입력칸에 글자를 치는 중이면 키보드 이동을 끔
  //    (예: 제목에 'Quiz'를 칠 때 Q가 이동으로 오작동하는 것 방지)
  if (event.target.closest('#title')) return;

  // 2) 누른 키를 대문자로 통일 (q, s 소문자도 인식)
  const key = event.key.toUpperCase();

  // 3) 이동에 쓰는 키인지 확인. 관련 없는 키면 아무 것도 안 함
  //    S·A·B·C는 그대로, Q는 미분류(pool)로 연결
  const keyToTier = { S: 'S', A: 'A', B: 'B', C: 'C', Q: 'pool' };
  const tier = keyToTier[key];
  if (!tier) return;

  // 4) 선택한 카드가 없으면 기존 안내 함수로 알려 줌
  if (!selected) { showMessage('먼저 영화 카드를 선택해 주세요.'); return; }

  // 5) 이미 있는 이동 함수를 그대로 재사용
  move(selected, tier);
});
// ▲▲▲ 여기까지 새로 추가한 부분 ▲▲▲
```

## 동작 규칙(왜 이렇게 했나)

- **제목 입력칸에 글자를 치는 중에는 키보드 이동을 끕니다.**
  예) 제목에 "Quiz"를 칠 때 Q 때문에 카드가 엉뚱하게 움직이지 않도록 막았습니다.
- **S·A·B·C·Q 외의 키(스페이스, 엔터 등)는 무시합니다.**
  그래서 관련 없는 키를 눌러도 안내 메시지가 쓸데없이 뜨지 않습니다.
- **카드를 고르지 않고 키를 누르면** "먼저 영화 카드를 선택해 주세요." 안내가 뜹니다.

## 바꾸지 않은 것

- 드래그해서 놓기, 글자 버튼 클릭, 영화 추가, '처음으로',
  브라우저 자동 저장, CSS 디자인, 영화 8개 목록 — 전부 그대로입니다.

## 외부 파일·서버 필요 여부

- 없습니다. HTML 파일 하나를 더블클릭해서 바로 열 수 있습니다.

## 직접 확인하는 방법

1. 카드 하나를 클릭해 선택 → S 키 → S칸으로 가나요?
2. S칸의 카드를 다시 클릭 → Q 키 → 미분류로 돌아오나요?
3. 아무 카드도 선택하지 않고 S 또는 Q → 안내 메시지가 뜨나요?
4. 제목칸에 "Quiz"를 칠 때 → 카드가 안 움직이고 메시지도 안 뜨나요?
5. 소문자 q 로도 미분류 이동이 되나요?
